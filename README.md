# 🎮 ARCADE — коллекция браузерных игр

**Три игры. Один портал. Выбирай и играй.**

ARCADE — игровой веб-портал на Python и Flask, объединяющий классические аркадные игры и трёхмерные шахматы. Все игры запускаются прямо в браузере, в том числе в GitHub Codespaces.

## 🦖 Dino Adventure

Бесконечный забег с постепенно растущей сложностью, движущимися пейзажами, кактусами и птицами.

- Три режима сложности и локальные рекорды.
- Монеты: +25 очков за каждую.
- Щит: защита от одного столкновения.
- Замедление: снижение скорости на пять секунд.
- Смена дня и ночи каждые 25 секунд.

| Управление | Действие |
| --- | --- |
| Пробел / ↑ | Прыжок, повторное нажатие — двойной прыжок |
| ↓ | Пригнуться |
| P | Пауза |

## 🧩 Tetris

Классическое поле 10 × 20 с адаптивным масштабированием под высоту окна.

- Семь типов фигур и перемешанный набор (7-bag).
- Предпросмотр следующей фигуры и удержание текущей.
- Контур места приземления, комбо и анимация очистки линий.
- Постепенное ускорение и сохранение личного рекорда в браузере.

| Управление | Действие |
| --- | --- |
| ← / → | Перемещение |
| ↑ | Поворот |
| ↓ | Ускорение падения |
| Enter | Мгновенный сброс |
| C | Удержание фигуры |
| Пробел / P | Старт и пауза |

## ♟️ Chess 3D

Шахматы с процедурно созданными объёмными фигурами, освещением и тенями на Three.js.

| Настройка | Варианты |
| --- | --- |
| Режим | Против компьютера / два игрока на одном устройстве |
| Сложность | Лёгкая / средняя / сложная |
| Цвет игрока | Белые / чёрные |
| Доска | Орех и клён / мрамор / изумруд / космос |
| Фигуры | Классика / серебро и золото / нефрит / неон |

Поддерживаются подсветка допустимых ходов, история партии, отмена ходов, разворот доски, переключение камеры и превращение пешки. Правила проверяет библиотека python-chess. Компьютер использует собственный алгоритм поиска ходов с ограниченной глубиной, не Stockfish.

## 🚀 Быстрый старт

### GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Denis-create-boop/games?quickstart=1)

В терминале выполните:

```bash
python -m pip install -r requirements.txt
python app.py
```

Откройте порт **5000** через **Open in Browser**. На главной странице выберите игру.

### Локальный запуск

```bash
git clone https://github.com/Denis-create-boop/games.git
cd games
python -m pip install -r requirements.txt
python app.py
```

Откройте [http://localhost:5000](http://localhost:5000).

## ℹ️ Особенности запуска

- Для браузерных игр Pygame устанавливать не требуется.
- Для объёмных шахмат необходимы WebGL и доступ к CDN Three.js. При недоступности 3D предусмотрена резервная 2D-доска.
- Рекорды аркад хранятся в текущем браузере, общей сетевой таблицы лидеров нет.
- Шахматы для двух игроков работают на одном устройстве; сетевой мультиплеер не реализован.
- Оригинальные Python-версии Dino и Tetris сохранены отдельно. Браузерные версии имеют расширенную механику.
- Сервер Flask предназначен для разработки и локального запуска.
