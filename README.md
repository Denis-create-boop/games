# ARCADE

Dino Adventure, Tetris и Chess 3D — игры в браузере.

```bash
pip install -r requirements.txt
python app.py
```

Откройте порт 5000. Для 3D используется Three.js с CDN; при недоступности WebGL предусмотрена 2D-доска. Шахматные правила проверяет python-chess. Оригинальные Python-версии Dino и Tetris сохранены.
